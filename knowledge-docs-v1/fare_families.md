## 1. Overview

This document defines the airline's fare family structure, including all included services, restrictions, and rules for each fare product. The airline operates five fare families across two cabin classes (Economy and Business). All customer-facing staff must understand the differences between fare families to accurately advise passengers and process bookings.

## 3. Detailed Fare Family Rules

### 3.1 Light Fare

**Target Segment:** Price-sensitive travelers, short trips, passengers who need only hand baggage.

| Rule | Detail |
|------|--------|
| **Booking classes** | L, V, N |
| **Minimum stay** | None |
| **Maximum stay** | 12 months |
| **Advance purchase** | None required |
| **Combinability** | Can be combined with other fare families in a round-trip itinerary |
| **Changes** | Not permitted. Ticket is non-changeable. |
| **Cancellation** | Non-refundable. Government-imposed taxes may be refunded upon written request within 12 months of ticket issue. Tax refund processing fee: EUR 25. |
| **Name change** | Not permitted. |
| **Transfer** | Not transferable. |
| **Routing** | Direct routing only (no free stopovers). |
| **Child discount** | 25% discount for CHD (2-11). INF pays 10% of adult fare. |

### 3.2 Classic Fare

**Target Segment:** Standard travelers who want included baggage and the flexibility to make changes.

| Rule | Detail |
|------|--------|
| **Booking classes** | Y, B, M, H |
| **Minimum stay** | None |
| **Maximum stay** | 12 months |
| **Advance purchase** | None required |
| **Combinability** | Can be combined with other fare families |
| **Changes** | Permitted with fee. Fee varies by route distance (EUR 75–150). Max 3 changes per ticket. |
| **Cancellation** | Refundable minus cancellation penalty. Penalty = same as change fee. Taxes fully refunded. |
| **Name change** | Spelling correction: Free (up to 3 characters). Full name change: EUR 50. |
| **Transfer** | Not transferable. |
| **Routing** | Direct and connecting routings. One free stopover on long-haul routes (>6 hours). |
| **Child discount** | 25% discount for CHD (2-11). INF pays 10% of adult fare. |

### 3.3 Flex Fare

**Target Segment:** Business travelers and those who need maximum flexibility.

| Rule | Detail |
|------|--------|
| **Booking classes** | K, S |
| **Minimum stay** | None |
| **Maximum stay** | 12 months |
| **Advance purchase** | None required |
| **Combinability** | Can be combined with other fare families |
| **Changes** | Free, unlimited changes. No fee, no fare difference within the same booking class. If the new flight is in a higher booking class, fare difference applies. |
| **Cancellation** | Fully refundable at any time before departure. Post-departure: unused segments refundable. |
| **Name change** | Spelling correction: Free. Full name change: Free (1 change). Additional name changes: EUR 50 each. |
| **Transfer** | Not transferable. |
| **Routing** | Direct and connecting routings. One free stopover on any route. |
| **Child discount** | 25% discount for CHD (2-11). INF pays 10% of adult fare. |

### 3.4 Business Saver Fare

**Target Segment:** Business travelers seeking Business class comfort at a value price.

| Rule | Detail |
|------|--------|
| **Booking classes** | D, I |
| **Minimum stay** | None |
| **Maximum stay** | 12 months |
| **Advance purchase** | None required |
| **Combinability** | Can be combined with Business Flex or Economy fare families |
| **Changes** | Free, unlimited changes. |
| **Cancellation** | Fully refundable. |
| **Name change** | Free (unlimited). |
| **Transfer** | Not transferable. |
| **Routing** | Direct and connecting routings. Two free stopovers. |
| **Child discount** | 25% discount for CHD (2-11). INF pays 10% of adult fare. |

### 3.5 Business Flex Fare

**Target Segment:** Premium business travelers who require the highest level of flexibility and service.

| Rule | Detail |
|------|--------|
| **Booking classes** | C, J |
| **Minimum stay** | None |
| **Maximum stay** | 12 months |
| **Advance purchase** | None required |
| **Combinability** | Can be combined with any fare family |
| **Changes** | Free, unlimited changes. No fare difference even if rebooking to a higher booking class. |
| **Cancellation** | Fully refundable at any time, including post-departure for unused segments. |
| **Name change** | Free (unlimited). |
| **Transfer** | Not transferable. |
| **Routing** | Any routing permitted. Two free stopovers. Open-jaw permitted. |
| **Child discount** | 25% discount for CHD (2-11). INF pays 10% of adult fare. |
| **No-show protection** | Full ticket value retained. No penalty. Rebookable within 12 months. |
| **Guaranteed rebooking** | In case of IROP, Business Flex passengers receive priority rebooking, including on partner airlines. |

## 4. Fare Family Pricing Structure

### 4.1 Relative Pricing (Indicative)

The following shows the typical price relationship between fare families for the same route and date:

| Fare Family | Price Index | Typical Price Range (Short-Haul Example) |
|-------------|-------------|------------------------------------------|
| **Light** | 1.0x (base) | EUR 39–199 |
| **Classic** | 1.3x–1.5x | EUR 59–299 |
| **Flex** | 1.8x–2.5x | EUR 89–499 |
| **Business Saver** | 3.0x–4.0x | EUR 199–799 |
| **Business Flex** | 4.0x–6.0x | EUR 299–1,199 |

> **Note:** Actual prices vary by route, demand, season, and advance purchase. The multipliers above are indicative only.

### 4.2 Fare Filing

- All fares are filed with ATPCO (Airline Tariff Publishing Company).
- Fare basis codes follow the format: `[Booking Class][Route Code][Fare Type]`
  - Example: `YOWRT` = Y class, one-way, round-trip pricing
  - Example: `LLON1` = L class, London, promotional fare 1
- Fare rules (conditions, penalties, etc.) are attached to each fare basis in the GDS.

## 5. Upselling Guidelines

### 5.1 When to Suggest an Upgrade

| Situation | Suggested Upsell |
|-----------|-----------------|
| Passenger books Light and asks about baggage | Suggest Classic (includes 1 bag, often cheaper than Light + bag add-on) |
| Passenger books Classic and mentions possible date change | Suggest Flex (free changes save potential fees) |
| Passenger books Economy Flex and values comfort | Suggest Business Saver (lounge + 2 bags + priority) |
| Corporate traveler on Business Saver | Suggest Business Flex (no fare difference on changes, fast track, premium WiFi) |

### 5.2 Upsell Value Messaging

| Fare Family | Key Value Message |
|-------------|-------------------|
| **Classic over Light** | "For just EUR [XX] more, you get a checked bag, seat selection, and the ability to change your flight." |
| **Flex over Classic** | "Upgrade to Flex for EUR [XX] more and enjoy free unlimited changes, full refundability, and priority boarding — perfect for plans that might change." |
| **Business Saver over Flex** | "For EUR [XX] more, fly Business class with 2 bags, lounge access, and a premium meal service." |
| **Business Flex over Saver** | "Business Flex gives you the ultimate flexibility with no fare difference on changes, fast track security, and full streaming WiFi." |

## 6. Fare Family Identification

### 6.1 How to Identify the Fare Family in a PNR

1. **Fare basis code:** Look at the fare basis in the ticket or pricing record. The first letter indicates the booking class, which maps to a fare family.
2. **Fare family indicator:** Most GDS systems display the fare family name alongside the fare basis.
3. **Baggage allowance:** The included baggage shown in the PNR's baggage record indicates the fare family.

### 6.2 Booking Class to Fare Family Mapping

| Booking Class | Fare Family | Cabin |
|--------------|-------------|-------|
| L, V, N | Light | Economy |
| Y, B, M, H | Classic | Economy |
| K, S | Flex | Economy |
| D, I | Business Saver | Business |
| C, J | Business Flex | Business |
| W | Premium Economy (future product) | Premium Economy |
