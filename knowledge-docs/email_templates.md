## 1. Overview

This document contains standardized email templates for key customer communications. All agents must use these templates as the basis for customer emails, personalizing the bracketed fields `[field]` with actual customer and booking data. Templates must not be modified in structure without approval from the Customer Communications team.

**General Email Rules:**
- Always address the passenger by name (Mr./Ms./Mx. [Last Name]).
- Include the booking reference (PNR) in the subject line where applicable.
- Use a professional, empathetic, and clear tone.
- Include the airline's privacy policy link in the footer.
- All emails must be sent from approved airline email addresses only.
- Do not include sensitive payment information (full card numbers) in emails.

## 9. Template Usage Guidelines

### 9.1 Personalization Rules

| Element | Rule |
|---------|------|
| **Passenger name** | Always use the passenger's title and surname (Mr. Smith, Ms. Garcia). Use first name only if the passenger has explicitly used it in prior communication. |
| **Bracketed fields** | All `[bracketed]` fields must be replaced with actual data. Never send an email with unreplaced brackets. |
| **Optional sections** | Sections in `[square brackets]` are conditional. Include only if applicable and remove the brackets. |
| **Tone** | Professional, empathetic, clear. Avoid jargon. Avoid over-apologizing. |
| **Language** | Default language is English. Use the passenger's preferred language if known and templates are available in that language. |

### 9.2 Do's and Don'ts

| Do | Don't |
|----|-------|
| ✅ Personalize with real booking data | ❌ Send with placeholder brackets |
| ✅ Include all relevant reference numbers | ❌ Include full credit card numbers |
| ✅ Mention passenger rights where applicable | ❌ Admit fault or liability beyond policy |
| ✅ Provide clear next steps | ❌ Use informal language or emojis |
| ✅ Proofread before sending | ❌ Copy-paste entire templates without review |
| ✅ Use approved email signatures | ❌ Include personal contact details |
